你在改什么？
每一个亮点都是一个 vertex；线条把相邻 vertex 连接成 triangles。

        
GPU 会做什么？
真正的 GPU 会并行处理每个 vertex，再把三角形光栅化为 pixels。

        
今天怎么二开？
先新增一个顶点属性，例如 color 或 weight，再让 draw 函数可视化它。
